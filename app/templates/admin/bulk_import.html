📥 Bulk Import / Update from Excel

How it works:

  • Upload an Excel file (.xlsx) with product data
  • Existing products (matched by name) will be updated
  • New products will be added automatically
  • Images must be added manually later from product edit page

Required Columns:

ColumnRequiredDescription
ProductName / Name✅ YesProduct name
Price✅ YesSelling price (e.g., 120)
CompareAtPrice / MRP❌ NoOriginal price for discount display
Stock / Qty❌ NoStock quantity (default: 0)
Category❌ NoCategory name (auto-created if new)
Unit❌ NoUnit like "1L", "500g", "pack"
